## Projects

### [2D CNC Printer](https://github.com/Mahmoudbat/2d-cnc-printer)

A DIY 2D CNC machine for drawing, engraving, and experimenting with different tools. Built around custom hardware, firmware, and G-code.

### [PC Stats Monitor](https://github.com/Mahmoudbat/PC-Stats-Monitor)

A Java-based hardware monitor that sends PC statistics to an ESP32 with an OLED display.

### [MyFeed](https://github.com/Mahmoudbat/MyFeed)

A local gallery focused on keeping photos private and accessible without relying on a cloud service.

### [Smart Home Security Hub](https://github.com/Mahmoudbat/Smart-Home-Security-Hub)

An ESP32 smart-home project using sensors and Blynk for monitoring and alerts.
